# Archive

A running directory of what I've worked on, most recent first. The three write-ups linked
from the [home page](/) go into real depth; everything else is listed here for
completeness.

## Property Assessment Review Generator

- **Status:** Active — USU Analytics Solutions Center
- **What it is:** Python port of a legacy R valuation pipeline plus the report engine that
  turns a parcel ID into a USPAP-compliant assessment review PDF.
- **Source:** Private client repository — no public link.
- [Read the write-up](/par-summit)

## nixtla-forecasting

- **Status:** Complete — April 2026
- **What it is:** Streamlit app benchmarking statistical, ML, and deep-learning forecasters
  on a shared five-window rolling backtest. Built for DATA 5630 (Deep Forecasting).
- **Source:** [hcronley/nixtla-forecasting](https://github.com/hcronley/nixtla-forecasting)
- [Read the write-up](/nixtla-forecasting)

## Flash

- **Status:** Archived
- **What it is:** Django + DRF backend and Expo/React Native client for a flashcard app —
  document processing, Gemini-backed card generation with a rule-based fallback, and SM-2
  spaced repetition.
- [Read the write-up](/flash)

## hcronley.github.io

- **What it is:** This site. Jekyll on GitHub Pages, hand-rolled layout and styles.
- **Source:** [hcronley/hcronley.github.io](https://github.com/hcronley/hcronley.github.io)
